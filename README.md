## 🎯 Quick Start

### For DSA Problems
1. Navigate to `dsa/` folder
2. Choose a topic (arrays, strings, trees, etc.)
3. View problem solutions with explanations
4. Each solution includes time/space complexity analysis

**Example Structure**:
```python
"""
Problem: Two Sum
Link: https://leetcode.com/problems/two-sum/

Approach: Hash Map
Time Complexity: O(n)
Space Complexity: O(n)
"""
```

### For ML Projects
1. Navigate to `ml-projects/` folder
2. Choose a project category
3. Follow the README in each project
4. Includes: Dataset, Notebook, Model, Results, Future Work

**Each project includes**:
- Problem Statement
- Dataset Description
- Model Architecture
- Training & Evaluation
- Results & Insights
- Future Improvements
